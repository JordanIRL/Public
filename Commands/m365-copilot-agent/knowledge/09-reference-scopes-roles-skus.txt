## Modules

- ExchangeOnlineManagement 3.10.1 manages Exchange Online, mailboxes, transport, EOP. Connect with `Connect-ExchangeOnline -UserPrincipalName admin@contoso.onmicrosoft.com -ShowBanner:$false`. Disconnect or verify with `Disconnect-ExchangeOnline -Confirm:$false` / `Get-ConnectionInformation`.
- ExchangeOnlineManagement 3.10.1 (same package) manages Purview: labels, DLP, retention, eDiscovery. Connect with `Connect-IPPSSession -UserPrincipalName admin@contoso.onmicrosoft.com`. Disconnect or verify with `Disconnect-ExchangeOnline -Confirm:$false` / `Get-ConnectionInformation`.
- MicrosoftTeams 7.9.0 manages Teams, Teams Phone, all `Cs*` cmdlets. Connect with `Connect-MicrosoftTeams`. Disconnect or verify with `Disconnect-MicrosoftTeams` / `Get-CsTenant`.
- Microsoft.Online.SharePoint.PowerShell 16.0.27515.12000 manages SPO/OneDrive tenant + sites (Windows only). Connect with `Connect-SPOService -Url https://contoso-admin.sharepoint.com`. Disconnect or verify with `Disconnect-SPOService` / `Get-SPOTenant`.
- PnP.PowerShell 3.4.1 manages Site content: lists, files, permissions. Connect with `Connect-PnPOnline -Url "https://contoso.sharepoint.com" -Interactive -ClientId <your-app-client-id>`. Disconnect or verify with `Disconnect-PnPOnline` / `Get-PnPConnection`.
- Microsoft.Graph 2.39.0 manages Entra ID, users, groups, licences, reports. Connect with `Connect-MgGraph -Scopes "User.Read.All","Group.ReadWrite.All" -NoWelcome`. Disconnect or verify with `Disconnect-MgGraph` / `Get-MgContext`.

PnP is the only one that requires your own Entra app registration. `Connect-MgGraph` has no `-Interactive` switch — browser sign-in is the default. Beta Graph cmdlets live in `Microsoft.Graph.Beta` as `Get-MgBeta*`.

## Cmdlet noun map — Exchange Online

- To List mailboxes in bulk — use `Get-EXOMailbox` (`Get-Mailbox` for writes/rare properties).
- To See size, item count, last logon — use `Get-EXOMailboxStatistics`.
- To Find any recipient type at once — use `Get-EXORecipient`, `Get-Recipient`.
- To Check who has access to a mailbox — use `Get-EXOMailboxPermission`, `Get-EXORecipientPermission` (SendAs), `Get-EXOMailboxFolderPermission`.
- To Grant access — use `Add-MailboxPermission`, `Add-RecipientPermission`, `Set-Mailbox -GrantSendOnBehalfTo`.
- To Convert to shared, set forwarding, litigation hold — use `Set-Mailbox`.
- To Distribution groups / M365 group mailboxes — use `Get-DistributionGroup`, `Get-DistributionGroupMember`, `Get-UnifiedGroup`, `Get-UnifiedGroupLinks`.
- To Rooms and equipment — use `Get-Mailbox -RecipientTypeDetails RoomMailbox,EquipmentMailbox`, `Get-CalendarProcessing`, `Get-Place`.
- To Trace a message — use `Get-MessageTraceV2`, then `Get-MessageTraceDetailV2` (90 days of data, max 10 days per query — page the range); older than 90 days: `Start-HistoricalSearch`.
- To Mail flow rules and connectors — use `Get-TransportRule`, `Get-InboundConnector`, `Get-OutboundConnector`, `Get-AcceptedDomain`, `Get-RemoteDomain`.
- To Anti-spam / anti-phish / Safe Links — use `Get-HostedContentFilterPolicy`, `Get-AntiPhishPolicy`, `Get-SafeLinksPolicy`, `Get-QuarantineMessage`.
- To Suspicious inbox rules — use `Get-InboxRule -Mailbox user@contoso.com`.
- To Protocols, OWA/ActiveSync, mobile devices — use `Get-CASMailbox`, `Get-MobileDevice`, `Get-MobileDeviceStatistics`.
- To Tenant-wide settings — use `Get-OrganizationConfig`, `Set-OrganizationConfig`.
- To Search the unified audit log — use `Search-UnifiedAuditLog` (EXO, not Purview).

## Graph delegated scopes by task

Scopes are consent only. You also need the Entra role in the third column, or the call still returns 403.

- For Read user objects — least-privilege delegated scope `User.Read.All`; Entra role usually needed: Directory Readers / Global Reader.
- For Create, update, disable users — least-privilege delegated scope `User.ReadWrite.All`; Entra role usually needed: User Administrator.
- For Reset a password — least-privilege delegated scope `User-PasswordProfile.ReadWrite.All`; Entra role usually needed: Helpdesk / Password Administrator.
- For Read groups — least-privilege delegated scope `Group.Read.All`; Entra role usually needed: Directory Readers.
- For Change group membership — least-privilege delegated scope `GroupMember.ReadWrite.All`; Entra role usually needed: Groups Administrator.
- For Create / delete groups — least-privilege delegated scope `Group.ReadWrite.All`; Entra role usually needed: Groups Administrator.
- For Read tenant SKUs and licence assignments — least-privilege delegated scope `LicenseAssignment.Read.All` (or `Organization.Read.All`); Entra role usually needed: Global Reader / Directory Readers.
- For Assign or remove licences — least-privilege delegated scope `LicenseAssignment.ReadWrite.All`; Entra role usually needed: License Administrator.
- For Read sign-in and directory audit logs — least-privilege delegated scope `AuditLog.Read.All`; Entra role usually needed: Reports Reader / Security Reader.
- For Read usage reports — least-privilege delegated scope `Reports.Read.All`; Entra role usually needed: Reports Reader.
- For Read Conditional Access policies — least-privilege delegated scope `Policy.Read.All`; Entra role usually needed: Global Reader / Security Reader.
- For Write Conditional Access policies — least-privilege delegated scope `Policy.ReadWrite.ConditionalAccess`; Entra role usually needed: Conditional Access Administrator.
- For Read role assignments — least-privilege delegated scope `RoleManagement.Read.Directory`; Entra role usually needed: Global Reader.
- For Assign directory roles — least-privilege delegated scope `RoleManagement.ReadWrite.Directory`; Entra role usually needed: Privileged Role Administrator.
- For Read auth method registration — least-privilege delegated scope `AuditLog.Read.All` (report) or `UserAuthenticationMethod.Read.All` (per user); Entra role usually needed: Authentication Administrator.
- For Read apps / service principals — least-privilege delegated scope `Application.Read.All`; Entra role usually needed: Global Reader.
- For Read devices — least-privilege delegated scope `Device.Read.All`; Entra role usually needed: Global Reader.
- For Read SharePoint sites via Graph — least-privilege delegated scope `Sites.Read.All`; Entra role usually needed: SharePoint Administrator.

## Admin roles by workload

- Exchange Online, EOP: the admin role that works is Exchange Administrator (Graph name: Exchange Service Administrator). Read-only equivalent: Global Reader (Exchange Recipient Administrator is write, not read-only).
- Purview / compliance: the admin role that works is Compliance Administrator, Compliance Data Administrator; plus a Purview role group (eDiscovery Manager, Organization Management). Read-only equivalent: Global Reader.
- Teams: the admin role that works is Teams Administrator; Teams Communications Administrator for voice only. Read-only equivalent: Teams Communications Support Specialist, Global Reader.
- SharePoint / OneDrive: the admin role that works is SharePoint Administrator. Read-only equivalent: Global Reader.
- Users, groups, licences: the admin role that works is User Administrator; License Administrator for licences only; Groups Administrator for groups. Read-only equivalent: Directory Readers, Global Reader.
- Sign-in / audit / reports: the admin role that works is Reports Reader, Security Reader. Read-only equivalent: same.
- Conditional Access, auth methods: the admin role that works is Conditional Access Administrator, Authentication Policy Administrator. Read-only equivalent: Global Reader.
- Role assignments, PIM: the admin role that works is Privileged Role Administrator. Read-only equivalent: Global Reader.
